🎵 Spotify Clone

A full-stack Spotify-inspired music streaming platform built with modern web technologies. The application allows users to authenticate with Google, browse albums and songs, stream music in real time, and interact through live chat. An admin panel is provided for managing music content.

🚀 Features
User Features
Google Authentication using Clerk
Browse Albums and Songs
Real-time Music Streaming
Play, Pause, Next, Previous Controls
Responsive UI for Desktop and Mobile
Real-time Chat System
User Profile Management
Admin Features
Secure Admin Dashboard
Upload Songs with Audio Files
Upload Album Covers
Create and Manage Albums
View Platform Statistics
Manage Music Library
Real-Time Features
Socket.IO powered live chat
Online user tracking
Instant message delivery
Real-time updates across clients
